# Counter App

A simple counter application with dark theme support.

## Features
- Increment/decrement counter
- Reset to zero
- Dark/light theme toggle
- Responsive design
- Theme preference persistence

## Tech Stack
- React 18 + TypeScript
- Vite (build tool)
- CSS Variables (theming)
- localStorage (theme persistence)

## Setup

### Prerequisites
- Node.js 18+
- npm/yarn/pnpm
